How It Works

01

Data

Trained on the full ClinVar VCF (~900 MB) with 750 K+ annotated variants across pathogenic and benign classifications.

→
02

Features

Extracts genomic (one-hot bases, allele frequency, HGVS, molecular consequence) and structural (AlphaFold2 pLDDT) features.

→
03

Model

PyTorch Deep Neural Network or Random Forest ensemble. Outputs a calibrated pathogenic probability between 0 and 1.

→
04

Report

Returns PATHOGENIC / BENIGN classification with confidence score via fast REST API.
